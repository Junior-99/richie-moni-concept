# Richie Moni — spatial showroom

An original six-page implementation with charcoal fields, acid-lime typography, condensed oversized type, a scroll-reactive 3D cabinet, product archive, individual product detail views, room planner, story/contact and workspace.

References inspected for composition and information architecture (no template code or assets copied):

- https://www.pinterest.com/pin/848295279846198718/ — product rows, restrained utility controls and separate shopping flow.
- https://decortemplates.webflow.io/ — separate home, collection, product, about and contact page hierarchy.
- https://tympanus.net/codrops/2026/03/09/building-a-scroll-reactive-3d-gallery-with-three-js-velocity-and-mood-based-backgrounds/ — scroll-driven depth as an interaction direction; the cabinet is original procedural Three.js geometry.

Use genuine seller photographs rather than generated product claims. The 3D cabinet is visibly labelled illustrative. No prices or live inventory are inferred from historical listings. Reduced-motion mode removes scrolling transitions. Mobile navigation uses a disclosure button.
